Drop your image files into THIS folder.

Use these exact filenames so index.html picks them up automatically:

  headshot.jpg       — photo of mom (square crops best — face centered)
  painting-1.jpg     — first painting
  painting-2.jpg     — second painting
  painting-3.jpg     — third painting
  painting-4.jpg     — fourth painting
  painting-5.jpg     — fifth painting
  painting-6.jpg     — sixth painting
  share-card.jpg     — image that shows up when the link is texted/posted
                       (1200 × 630 pixels works best — could be a hero painting)

If you have more or fewer than 6 paintings, that's fine — just add/remove
.piece blocks in index.html (search for "Repeat one .piece block" to find them).

Image tips:
  - JPG, under 500 KB each (compress at squoosh.app if huge)
  - Long edge ~1600 px is plenty (4× phone-screen sharp, still small)
  - Shoot in even daylight, no flash, fill the frame with the painting
